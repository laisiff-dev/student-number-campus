# 南臺灣 (台南 / 高雄 / 屏東) 各校 GIS 動態地圖與學生人數分析儀表板
> **Tainan, Kaohsiung & Pingtung School GIS Intelligence System**

本專案為針對南臺灣三大縣市（台南市、高雄市、屏東縣）共 **91 所學校**（包含大專院校、高級中等學校、國民中學及偏鄉/山區/離島學校）建置之現代化 GIS 動態地圖與年級演變分析儀表板。

---

## 🌟 系統核心功能亮點

1. **🏛️ 教育部公開資料庫權威對照 (MOE Open Data as Primary Source)**：
   - 數據以教育部統計處及教育部大專校院校務資訊公開平台核定數據為主，並配備教育部核定學校代碼 (`moeCode`) 與雙軌直連查核按鈕。

2. **🗺️ 互動式 GIS 動態地圖 (Leaflet.js Dynamic Map)**：
   - 涵蓋北起台南後壁白河、東至高雄桃源那瑪夏、南至屏東恆春滿州與離島小琉球之 91 所學校。
   - 支援自動邊界適應 (Auto-Fit Bounds)、明亮/深色圖資切換與地圖點顯浮動彈窗。

3. **📊 基準年級人數變化分析 (Highest Grade Baseline Progression Model)**：
   - 以最高年級（高三／九年級／碩博大四）為 100% 基準 (Baseline)，展現低年級相對最高年級之規模差異與新生成長率。

4. **🏞️ 偏鄉與原民山區獨立統計專區**：
   - 收錄 31 所偏鄉、原民山區、離島與沿海學校，設有獨立篩選按鈕與特偏標籤。

5. **📈 學制佔比 (%) 對照矩陣**：
   - 將各校學生人數轉化為佔該學制統計總人數之比例 (%)，提供清晰客觀之規模佔比比較。

## 📁 專案架構

```
├── index.html       # Dashboard 主頁面與響應式玻璃質感版面
├── styles.css       # CSS 設計系統、現代 dark mode 與 Leaflet 標記樣式
├── data.js          # 91 所學校完整 JSON 數據庫（含座標、人數、年級、MOE代碼、偏鄉標籤）
├── app.js           # 儀表板邏輯、Leaflet 地圖引擎、Chart.js 圖表建構器與篩選核心
└── README.md        # 專案說明文件
```

您可以直接使用靜態網頁伺服器開啟：
